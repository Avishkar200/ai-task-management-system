 Python & AI Integration Intern – 24-Hour 
 Assessment 
 AI-Powered Task Management System 
 Build a simple  AI-Powered Task Management System  using  Python. 
 The application should allow authenticated users to manage tasks and should integrate an AI 
 service for task-related functionality. 
 The primary focus is  Python backend development, REST  APIs, authentication, database 
 usage, authorization, and AI API integration  . 
 1. Technology Requirements 
 Use: 
 ●  Python 
 ●  FastAPI or Flask 
 ●  MySQL or PostgreSQL 
 ●  JWT  authentication 
 ●  Any commonly used LLM API such as: 
 ○  OpenAI 
 ○  Google Gemini 
 ○  Anthropic 
 ○  Other equivalent provider 
 You may use additional Python libraries where appropriate.

 Implement  at least one  AI-powered feature from the following: 
 Option A: Generate Task Description 

 None  
 None

 ●  POST /api/tasks/{id}/summarize

 AI Requirements 
 ●  Store the AI API key in an environment variable. 
 ●  Do not commit API keys or  .env  files.
